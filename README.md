# GoreBox27 website

This is a static website. GitHub Pages should publish the repository root directly.

## GitHub Pages setup

1. Push the contents of this repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. Wait for the Pages deployment to finish and open the generated URL.

The site uses relative asset paths (`./styles.css`, `./script.js`, and `./public/...`) so it works both at a repository URL such as `https://username.github.io/repository-name/` and at a custom domain.

The download buttons intentionally open the external destination `https://apk-done.co` in a new tab. Verify APK sources and scan files before installing.
